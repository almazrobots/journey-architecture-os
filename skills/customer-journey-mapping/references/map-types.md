# Customer journey map types

## Current state
Use to diagnose what happens now.

## Target state
Use to define intended future experience. Every target-state element should either:
- solve an evidenced problem;
- enable a desired outcome;
- implement an explicit experience principle;
- test a strategic hypothesis.

## Transitional state
Use when migration matters. This prevents teams from designing an ideal endpoint while ignoring the experience during rollout.

## Context / day-in-the-life
Use when the organization's touchpoints are only a small part of the customer's broader effort.

## Hypothesis map
Use when research is insufficient. Mark assumptions clearly and treat the map as a research instrument.
