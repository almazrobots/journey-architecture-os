# Decomposition heuristics

## Split when
- a different actor becomes primary;
- the desired outcome changes;
- the trigger is materially different;
- governance requires different owners/metrics;
- research populations differ;
- branches become hard to compare.

## Do not split merely because
- channel changes;
- internal team changes;
- a system handoff occurs;
- a single stage contains multiple touchpoints.

## Granularity test

A useful L2 journey should be:
- understandable in one sentence;
- meaningful to the actor;
- measurable;
- researchable;
- improvable by a cross-functional team.

If it is "everything from awareness to advocacy," it is probably a lifecycle, not one actionable journey.
